## Complete reference

Historical reports retain the date, verified environment, scope and limitations of
the original work. A recorded result describes that run; it is not a claim about
every later revision. Raw logs, binary artifacts and source-code identifiers are
preserved as evidence. Some historical reports reference temporary run directories
or evidence files that are not included in a fresh checkout; those original
paths are retained as provenance.
