# Устойчивость признаков покрытия

Это краткое руководство. [Полное определение, настройка и статусы](../../feature-stability.md) опубликованы на английском.

Для одного проверенного входа EFZ берёт полные множества признаков каждого исполнения: `U = union(F₁…Fᵣ)`, `I = intersection(F₁…Fᵣ)`. `feature_stability = 100 × |I| / |U|`. Для кампании EFZ складывает `|I|` и `|U|` **по отдельным группам входов**, затем делит суммы. Минимум два валидных повтора и непустой `U` обязательны; иначе процент отсутствует. Пустой корректный trace отличается от отсутствующего trace.

В isolated режиме 20 наблюдений одной группы обычно требуют 19 дополнительных запусков цели. Диагностические вызовы не входят в primary exec/s и не меняют RNG мутаций. TUI показывает процент, статус, число проверенных групп и возраст последнего измерения. `100%` означает лишь отсутствие различий в выполненных наблюдениях.

## Persistent target / same-sequence

Для persistent target аудит сравнивает один и тот же шаг после одинакового полного prefix в независимых эпохах. Scope — `audited_sequence_steps`; разные prefixes образуют разные группы. Дополнительная стоимость 20 наблюдений шага после prefix длины `k` может составить `19 × (k + 1)` диагностических input executions, если primary sample пригоден. Изменение поведения при разных prefixes — history sensitivity, а не доказательство недетерминизма.
