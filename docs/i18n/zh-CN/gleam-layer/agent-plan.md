契约 v1，需求 2.0-native（2026-10-07）。
此会话全部修改由单一负责人完成。未启动子代理：用户提供 COMMON_CONTEXT，
未显式调用软件包单独的编排提示词。
不得把此实现描述为委派工作或独立子代理审查。实现前已归档基线。

P0 -> 基线和目标及覆盖源码审计。
P1 -> 固定 contracts.md 和实际源码映射。
P2 -> 无依赖固定版本 Gleam 软件包、经检查适配器、可选构建。
P3 -> 类型化原始种子、现有 staged 计划中的有界提供器、配方模式 3 及操作 v2；
旧配方模式 1/2 继续支持。
P4 -> 纯有界观察器、判定器和串行语料语义接纳。
P5 -> 原始与属性重放、有限最小化器、回归、A/B/B2 和同引擎短系列；
性能优势仍是独立未解问题。

不编辑用户需求、原始种子语料或全局工具链。
不执行提交、分支、推送、PR 或发布。
